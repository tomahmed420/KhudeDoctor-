# Wonders of the Human Body (শরীরের বিস্ময়)

An interactive, kid-friendly educational application that lets children explore human anatomy, understand how vital organs function, learn surprising science facts, and discover reflections of gratitude.

## Features

- **Interactive Body Silhouette & Grid View**: Explore each vital organ (heart, brain, lungs, eyes, stomach, liver, kidneys, and more) on an interactive body diagram or organ grid.
- **Detailed Organ Exploration**:
  - **কীভাবে কাজ করে (How it works)**: Simplified child-friendly mechanical explanations.
  - **মজার তথ্য (Fun Facts)**: Engaging scientific trivia with friendly icons.
  - **সুবহানাল্লাহ (Spiritual Reflection)**: Reflections on the marvel of creation and gratitude.
- **Bilingual Text-to-Speech (TTS)**: Dynamic Bengali voice synthesis with automatic pronunciation upon opening organ cards.
- **Interactive Quiz Modes**:
  - **⚡ দ্রুত কুইজ (Quick Quiz)**: 5 fun, fast questions with celebratory confetti.
  - **🏆 চ্যালেঞ্জ মোড (Challenge Mode)**: Comprehensive question suite covering all anatomy topics.
- **Optimized Mobile UX**: Responsive touch cards, comfortable reading typography with crisp Google Bangla fonts (`Hind Siliguri`), and fluid layout.

## Tech Stack

- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS, Lucide React icons, shadcn/ui components
- **Animations**: Framer Motion & Canvas Confetti
- **Audio/Speech**: Web SpeechSynthesis API with Bengali Voice Detection

## Getting Started

```sh
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```
